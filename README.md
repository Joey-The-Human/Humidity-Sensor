# Humidity-Sensor
Open source, cheap and 3D printed humidity sensor meant to keep track of a rooms humidity and temperature. 

# Documentation: 
    - In the "Resources" Folder there is documentation that's included to give 
    vital information about each part used.Each PDF was crafted to list specification sheet for each part.
    Including the following:
        - Pinout layout 
        - voltage sensitivity
        - Part Number & purpose
        - Part Specifications
        - List any special Quirk about it. 
        - Arduino IDE Setup Instruction
        - Example code so users can double check to see the board is good or faulty. 
        - Citations used to create the spec sheet. Feel free to check out said sources for more information. 

# Notes:
    - I'm Designing this to be easy to repaired/maintained. Along with flexability thus due to the Buck converter (TPS63070) many different battery configs can be used. Thus use what you have laying around to get the voltage to a stable 3.3V.
